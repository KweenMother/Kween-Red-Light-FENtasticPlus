⚙️ A: Kodi Settings (Before Installing Add-ons)

1. Open Kodi and select the ⚙ Settings gear icon.
2. Enable Unknown Sources: System > Add-ons > Unknown sources = ON

Player Settings (Set to "Expert")

Player > Videos > Adjust display refresh rate = Off
Player > Videos > Sync playback to display = Enabled
Player > Videos > Allow hardware acceleration = ON
Player > Videos > Allow use DXVA video super resolution = OFF (Keep disabled unless you have high-end hardware like an NVIDIA RTX or Intel Arc GPU. It can cause playback issues on most streaming boxes.)

Media Settings

Media > General > Show parent folder items = Off
All other Media settings are already set correctly by default. No further changes needed.

System Settings

System > Audio > Output configuration = Best match
System > Add-ons > Updates = Never check for updates
✅ Kodi settings are ready!

🧱 B: Install Add-ons & Skin (From Red Wizard Repo)

1. Add the Red Wizard Source: Settings > File Manager > Add source > Enter https://repo.redwizard.xyz > Name it "Red Repo".
2. Install the Repository: Go back to Settings > Add-ons > Install from zip file > Select "Red Repo" > Select repository.redwizard.zip.
3. Install Gears Scrapers (Primary Scraper): Install from repository > The Red Repo > Program add-ons > Gears Scrapers > Install.
4. Install Cocoscrapers (Backup Scraper): In the same Program add-ons list, select Cocoscrapers > Install. (Having both gives you a safety net.)
5. Install Red Light: Go back to The Red Repo > Video add-ons > Red Light > Install.
6. Install YouTube (for Trailers): In Video add-ons, select YouTube > Install.
7. Install FENtastic+ Skin: Go back to Install from repository > Choose 709 Repository (you may need to add the source from the "Main Source" section first) > Look and feel > Skin > FENtastic > Install.
NOTE: The Red Wizard Repo also contains a 4K Subtitles repository. This is an alternative subtitle downloader. You can safely ignore it for now; your main subtitle setup will be handled later.
✅ All core add-ons and the skin are installed!

🔴 C: Red Light Configuration

NOTE: Red Light has many settings. We will focus on the essentials. You can fine-tune the rest later.

Accounts Tab (The Essentials)

1. Authorize Trakt: Open Red Light > Tools > Settings > Accounts > Trakt > Authorize. Follow the on-screen code at trakt.tv/activate.
2. Authorize Real-Debrid: Accounts > Real-Debrid > Authorize. Follow the code at real-debrid.com/devices.
3. Enable Gears Scrapers: Accounts > External Scrapers > Enable = ON > Choose External Scrapers Module > Select Gears Scrapers.
4. (Optional) Enable Cocoscrapers as Backup: If you want a second scraper, select Cocoscrapers Module from the same list. It will be used if Gears fails.

General Settings (Recommended)

Playback > Movies > Auto Play = ON
Playback > Episodes > Auto Play = ON
Playback > Episodes > Autoplay next episode = ON
Results > Display > Scraper timeout = 5 (increase to 10 if you get no sources)
✅ Red Light is now configured with the best scrapers!

🎨 D: FENtastic+ Skin Configuration

1. Go to Settings > Skin settings
2. Main menu items > Remake menus and widgets > OK (This resets to a clean slate).
3. Set Movies Menu: Main menu items > Movies > Set main menu path > Red Light > Movies > Use as path.
4. Set TV Shows Menu: Main menu items > TV Shows > Set main menu path > Red Light > TV Shows > Use as path.
5. Add Widgets (Optional but Recommended): Under Movies and TV Shows, select Set widgets > Widget 1 > Red Light > Movies/TV Shows > Trending > Use as path. Choose Poster for the display type.
6. Enter MDBLIST API Key: Skin settings > Ratings/Trailers > Enter your MDBLIST API key and enable all options.
7. Set Search Provider: Skin settings > Search > Set Search Provider = Red Light.
✅ Your FENtastic+ skin is now personalized!

The Loop (Live TV & Sports)

1. From the Red Wizard Repo: Install from repository > The Red Repo > Video add-ons > The Loop > Install.
2. Also install Jet Proxy: It will be listed as an additional add-on. Install it for smooth playback.

The Crew (Sports)

1. Add Source: File Manager > Add source > https://team-crew.github.io > Name it "The Crew".
2. Install Repo: Install from zip file > The Crew > repository.thecrew-x.x.zip.

Mad Titan Sports

1. Add Source: File Manager > Add source > https://magnetic.website/repo > Name it "Mad Titan".
2. Install Repo: Install from zip file > Mad Titan > repository.Magnetic-x.x.zip.
3. Install Add-on: Install from repository > Magnetic Repo > Video add-ons > Mad Titan Sports > Install.

YouTube (For Trailers)

Already installed in Step B. The first time you play a trailer, YouTube will ask you to configure settings. Follow the on-screen wizard (English, region, recommended settings) and you're done. No SlyGuy needed.
✅ All extras are installed!

✨ F: Finish Line & Final Notes

Subtitles: For subtitles, go to Settings > Add-ons > Install from repository > Kodi Add-on Repository > Subtitles > OpenSubtitles.com > Install. Configure it with your username and password.
4K Subtitles: If you want an alternative, the 4K Subtitles add-on is available in the Red Wizard Repo under Program add-ons. It works similarly to OpenSubtitles.
REMINDER: SIMKL was considered for watch tracking, but Trakt is recommended because it saves your movie progress. SIMKL marks movies as finished as soon as you start them, which is not ideal for most users.
