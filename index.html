🅱️ B: Install Everything from the Red Wizard Repo

WHY ONE REPO? The Red Wizard Repo is a one-stop shop. It contains Red Light, Gears Scrapers, YouTube, plus sub-repos for FENtastic+ (709 Repo), The Loop, a4kSubtitles, and CocoScrapers. We'll install everything from here so you don't have to add five separate sources.
1. Add the Red Wizard source: Settings > 📂 File Manager > Add source > Press Enter on <None> > Type https://repo.redwizard.xyz/ > Select OK > Type "Red Wizard" as the name > Press OK.
2. Install the Red Wizard repository: Go back to Settings > Add-ons > Install from zip file > Select "Red Wizard" > Select the repository zip file > Wait for the install confirmation.
3. Install the Red Light add-on: Install from repository > The Red Wizard Repo > Video add-ons > Red Light > Install.
4. Install Gears Scrapers: Install from repository > The Red Wizard Repo > Program add-ons > Gears Scrapers > Install. (This is the primary scraper we'll enable in Step C.)
5. Install YouTube (for Trailers): Install from repository > The Red Wizard Repo > Video add-ons > YouTube > Install.
6. Install Cocoscrapers: Install from repository > The Red Wizard Repo > Add-on repository > CocoScrapers Repository (if it's not already listed) > Then go to Install from repository > CocoScrapers Repo > Program add-ons > CocoScrapers Module > Install.
7. Install The Loop: In the same Red Wizard Repo > Add-on repository > The Loop Repository (if not already listed) > Then Install from repository > Loop Repo > Video add-ons > The Loop > Install. When asked to install additional add-ons, say YES to install Jet Proxy as well.
8. Install a4kSubtitles: In the same Red Wizard Repo > Add-on repository > a4kSubtitles Repository > Then Install from repository > a4kSubtitles Repo > Program add-ons > a4kSubtitles > Install.
9. Install FENtastic+ Skin: In the same Red Wizard Repo > Add-on repository > 709 Repository (if not already listed) > Then Install from repository > 709 Repo > Look and feel > Skin > FENtastic > Install. Say YES to switch to this skin and keep it.
YOUTUBE TRAILER NOTE: The first time you play a trailer from inside Red Light, YouTube will launch its own setup wizard. Answer: Configure Settings? Yes. Recommended Values? Yes. Performance Settings? Yes. Language and Region? Yes. Subtitles? No. My Location? No. Minimal Listings? No. Refresh settings.xml? No. That's it—YouTube is ready.
✅ Everything from the Red Wizard Repo is now installed!

🔑 C: Red Light Accounts Tab Settings

NOTE: Follow these in the order shown. Most settings live under the Accounts tab inside Red Light.

#1 Authorize Trakt

1. Settings > Add-ons > My add-ons > Video Add-ons
2. Select Red Light > Open > Tools🛠
3. Select Settings
4. Accounts > TRAKT > Select Authorize
5. Note the Authorization code
6. Using a web browser visit trakt.tv/activate and enter the authorization code (You must be logged into your Trakt account)
7. Select Yes to authorize Red Light with Trakt.
✅ Trakt is now integrated with Red Light!

#2 Authorize OMDB

1. Accounts > OMDB > API KEY
2. Enter the Key code emailed from omdbapi.com
3. Select OK
✅ OMDB is now enabled in Red Light!

#3 Enable External Scrapers (Gears Primary, Coco Backup)

1. Accounts > External Scrapers > Enable = ON
2. Accounts > External Scrapers > Choose External Scrapers Module > Select Gears Scrapers
3. Select OK
WHY BOTH? Gears Scrapers is the primary (actively maintained and recommended). CocoScrapers is installed as a backup. If Gears ever has issues, come back to this setting and swap to CocoScrapers. Having both installed means you're never stuck.
✅ Gears Scrapers is now enabled (with CocoScrapers ready as backup)!

#4 Authorize All Debrid (#1 Choice)

1. Accounts tab > All Debrid > Select Authorize
2. Note the Authorization code
3. Using a web browser visit alldebrid.com/pin and enter the authorization code (You must be logged into your All Debrid account).
4. Back in Kodi, you will see a success message. Press OK to continue.
5. Enable SEARCH CLOUD STORAGE and its categories
6. Priority set to 1
✅ All Debrid is now integrated with Red Light!

#5 Authorize Real-Debrid (Optional Backup)

1. Accounts tab > Real Debrid > Select Authorize
2. Note the Authorization code
3. Using a web browser visit real-debrid.com/devices, Add a new Device & enter the authorization code (You must be logged in to your Real-Debrid account).
4. Type "Red Light" and press Set that name.
5. Back in Kodi, you will see a success message. Press OK to continue.
6. Enable SEARCH CLOUD STORAGE and its categories
7. Priority set to 2
✅ Real-Debrid is now integrated with Red Light as a backup!
8. Scroll 👈🏾 Left & 🆙 up to the General Tab

🗣️ H: Subtitles (a4kSubtitles)

NOTE: a4kSubtitles is our main subtitle downloader (installed in Step B). It pulls subtitles from multiple sources at once, so you don't need to hunt for them manually.

Configure a4kSubtitles

1. Open a4kSubtitles: Settings > Add-ons > My add-ons > Program Add-ons > a4kSubtitles > Configure
2. Choose your subtitle source: Inside a4kSubtitles settings, you'll see two OpenSubtitles options:
  • opensubtitles — uses an OpenSubtitles.com account for more sources
  • opensubtitles quick — works with no account needed
3. Pick whichever fits you: Use "opensubtitles quick" if you don't want an account, or "opensubtitles" if you have one and want access to more subtitles.
4. Enable the sources you want: Turn on any additional subtitle providers you want to use, then press OK to save.

Optional: OpenSubtitles.com Account

If you want access to the full OpenSubtitles catalog, you can create a free account at https://opensubtitles.com, then come back to a4kSubtitles settings and enter your credentials. This step is completely optional — a4kSubtitles works fine without it.
✅ Subtitles are now configured.
